Arquitetura da Aplicação & Justificativa Técnica

Mapeamento direto dos requisitos acadêmicos da atividade para a implementação prática

🌐 1. Entrega & HTML5

Resolução de domínio via DNS, transporte seguro com HTTPS/TLS 1.3 e estrutura HTML semântica (landmarks <header>, <main>, <article>, <dialog>) garantindo acessibilidade WCAG e indexação SEO.

🎨 2. Apresentação & CSS

Layout fluido mobile-first, controle de Box Model com box-sizing: border-box, CSS Grid e Flexbox, tokens centralizados (CSS variables) e suporte a tema escuro/claro.

⚡ 3. Interatividade & DOM

Consumo assíncrono de API RESTful (JSON) com fetch e async/await, busca textual com debounce, delegação de eventos e manipulação reativa do DOM.

🚀 4. Transição para SPA

Planejamento para framework moderno (React/Vite): componentização modular, fluxo unidirecional de dados (state/props), roteamento no cliente com History API e pipeline de build com tree-shaking.
