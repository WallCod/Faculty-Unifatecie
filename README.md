## 📌 Sobre Este Repositório

Bem-vindo ao repositório central do curso de **Bacharelado em Engenharia da Computação** do **Centro Universitário UniFatecie**. 

Este espaço é dedicado a documentar a evolução acadêmica e técnica ao longo da graduação, abrangendo desde os fundamentos de baixo nível (Arquitetura de Computadores, Linguagem C, Sistemas Operacionais e Estruturas de Dados) até o desenvolvimento de sistemas corporativos em Java e engenharia de software web full-stack de alto desempenho (Front-End moderno, APIs RESTful e SPAs).

Atualmente na **reta final da graduação em Engenharia da Computação**, com preparação para ingresso em programa de **Pós-Graduação *Stricto Sensu* (Mestrado)** com foco em Engenharia de Software, Sistemas Distribuídos e Inteligência Artificial.

## 🚀 Como Executar os Projetos Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/WallCod/Faculty-Unifatecie.git
   cd Faculty-Unifatecie
   ```

2. **Para executar a aplicação do Assistente Virtual de IA (Módulo 6):**
   ```bash
   cd "6 - Inteligência Artificial"
   # Usando Python:
   python -m http.server 8080
   # Ou com Node.js:
   npx serve .
   ```
   Abra `http://localhost:8080` no seu navegador.

3. **Para executar a aplicação de Front-End (Módulo 5):**
   ```bash
   cd "5 - Desenvolvimento Front-End"
   # Usando Python:
   python -m http.server 3000
   ```
   Abra `http://localhost:3000` no seu navegador.
