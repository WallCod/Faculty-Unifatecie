## 📌 Sobre Este Repositório

Bem-vindo ao repositório central do curso de **Bacharelado em Engenharia da Computação** do **Centro Universitário UniFatecie**. 

Este espaço é dedicado a documentar a evolução acadêmica e técnica ao longo da graduação, abrangendo desde os fundamentos de baixo nível (Arquitetura de Computadores, Linguagem C, Sistemas Operacionais e Estruturas de Dados) até o desenvolvimento de sistemas corporativos em Java e engenharia de software web full-stack de alto desempenho (Front-End moderno, APIs RESTful e SPAs).

Atualmente na **reta final da graduação em Engenharia da Computação**, com preparação para ingresso em programa de **Pós-Graduação *Stricto Sensu* (Mestrado)** com foco em Engenharia de Software, Sistemas Distribuídos e Inteligência Artificial.

## 🌟 Atividade em Destaque (Avaliação Atual)

### [📁 5 - Desenvolvimento Front-End: Catálogo Online Responsivo & Interativo](./5%20-%20Desenvolvimento%20Front-End)
> **Tema:** Funcionamento da Web, HTML5 Semântico, CSS3 Responsivo, JavaScript/DOM, Consumo de API RESTful JSON e Modernização SPA.

- **Aplicação Web:** Interface completa e responsiva para catálogo da livraria acadêmica (*Livraria Alexandria*).
- **Recursos Práticos:** Busca em tempo real com *debounce*, filtros dinâmicos por categoria, ordenação multicritério, modal acessível nativo (`<dialog>`), temas Dark/Light com tokens CSS e consumo de API REST assíncrona.
- **Relatório Técnico e Conceitual:** Documento aprofundado respondendo a todos os requisitos solicitados pela disciplina:
  👉 **[Acesse o Relatório Técnico Conceitual (RESPOSTA_TECNICA.md)](./5%20-%20Desenvolvimento%20Front-End/RESPOSTA_TECNICA.md)**

## 🛠️ Stack Tecnológica Dominada no Curso

- **Linguagens & Baixo Nível:** C, Java, JavaScript (ES6+), TypeScript, SQL
- **Web & Front-End:** HTML5 Semântico, CSS3 Moderno (Grid, Flexbox, Custom Properties), React, Vite, WAI-ARIA
- **Arquitetura & Engenharia:** Modelo Cliente-Servidor, Protocolos HTTP/HTTPS, DNS, APIs RESTful, MVC, Padrões de Projeto (GoF), Clean Code
- **Ferramentas & DevOps:** Git, GitHub, Linux, Bash, VS Code / Antigravity IDE

## 🚀 Como Executar os Projetos Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/WallCod/Faculty-Unifatecie.git
   cd Faculty-Unifatecie
   ```

2. **Para executar a aplicação de Front-End:**
   ```bash
   cd "5 - Desenvolvimento Front-End"
   # Usando Node.js:
   npx serve .
   # Ou com Python:
   python -m http.server 3000
   ```
   Abra `http://localhost:3000` no seu navegador.
